Roloehow it works

Each person's own assistant reads. Roloe only connects, checks and forgets.

Each person's own machine and subscriptionRoloe services: no model, no credentials

The coordinator holds each person's Roloe card key as a hash and nothing else: no Anthropic, OpenAI or ChatGPT login ever reaches it. Each assistant reads only that encounter's overlapping passages and posts findings that the coordinator checks in code. On Elastic Cloud Serverless the coordinator's encounter_id filter is the scope (Serverless won't mint a scoped key from an API key); on a licensed cluster each encounter gets its own document-level-security key.
